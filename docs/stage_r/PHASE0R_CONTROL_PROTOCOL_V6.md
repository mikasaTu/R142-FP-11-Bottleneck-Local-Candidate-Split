# Stage-R Phase-0R control protocol v6

Control protocol ID: `r142-stage-r-controls-v6`.

V6 changes only the lane-choice bias coefficient from 0.055 to 0.15. With
states centered at 7.5 and Gaussian scale 0.28, outer bias-opposed groups now
have absolute means 0.675--1.125 before noise. The v5 aperture map, geometry,
feedback, null, thresholds, shuffles and pass conditions are unchanged.
